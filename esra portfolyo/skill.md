**Odak Alanı:** Multidisipliner Tasarım 

---

## 📊 1. Temel Frontend ve Mimari Yetkinlikler

* **React Component Mimarisi:** Projenin atomik tasarıma uygun olarak parçalanması (Örn: `ProjectCard` bileşeninin portfolyo listesinde tekrar tekrar map edilmesi).
* **Asenkron Durum Yönetimi (Redux Thunk):** Veritabanından (API) gelen verilerin gecikme (loading) süreçlerinin merkezi state üzerinde yönetilmesi.
* **Bootstrap 5 Grid & Flexbox Master:** Tasarımcı hassasiyetiyle, nesnelerin tüm ekran çözünürlüklerinde hizalı durmasını sağlayan `.container`, `.row` ve `.col` mimarisi.

---

## 🛠️ 2. Projede Kullanılan Araç Seti (Tech Stack)
| Teknoloji | Kullanım Amacı |
| :--- | :--- |
| **React (Vite)** | Hızlı, modüler ve tek sayfalık (SPA) mimari. |
| **Redux Toolkit** | Projelerin ve kariyer geçmişinin merkezi hafızada tutulması. |
| **Bootstrap 5** | Responsive grid, buton grupları, progress barlar ve form tasarımları. |
| **Bootstrap Icons** | Tasarımcı linkleri (Behance, LinkedIn) için vektörel ikon seti. |
| **JSON Server** | Gerçek bir REST API gibi çalışan mock veri sunucusu. |
